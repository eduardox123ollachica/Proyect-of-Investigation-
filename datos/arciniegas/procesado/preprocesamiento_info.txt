PREPROCESAMIENTO DATASET ARCINIEGAS
======================================================================


CLASES
----------------------------------------------------------------------
0: DETENIDO
1: VELOCIDAD MEDIA
2: VELOCIDAD ALTA

DATOS CRUDOS
----------------------------------------------------------------------
Cada JSON contiene aceleracion triaxial: ax, ay, az.
Frecuencia de muestreo esperada: 100.0 Hz.
interval_ms esperado: 10 ms.
Las capturas auditadas tienen 300 muestras, equivalentes a 3 s.

SEGMENTACION
----------------------------------------------------------------------
Tamano de ventana / FFT: 16 muestras.
Overlap: 50%.
Hop: 8 muestras.
Para un archivo de 300 muestras se generan 36 ventanas.
No se mezclan archivos entre training y testing: cada ventana conserva el split de su JSON de origen.

FEATURES EXTRAIDAS
----------------------------------------------------------------------
Se extraen 7 caracteristicas por cada eje (X, Y y Z), para un total de 21 features por ventana:
- RMS
- Skewness
- Kurtosis
- Energia espectral
- Frecuencia dominante
- Amplitud dominante
- Entropia espectral

Antes de la FFT se resta la media de cada ventana para reducir la componente DC, especialmente la gravedad en az. El RMS se calcula sobre la senal original de la ventana.

FFT
----------------------------------------------------------------------
Se utiliza np.fft.rfft con N=16 y fs=100 Hz.
La resolucion espectral es fs/N = 6.25 Hz por bin.
La frecuencia dominante se obtiene ignorando el bin DC.

NORMALIZACION
----------------------------------------------------------------------
En esta etapa NO se normalizan/estandarizan las features. Se guardan valores crudos para mantener trazabilidad. Si posteriormente se usa StandardScaler, debe ajustarse solo con training y aplicarse despues a testing.

NOTA METODOLOGICA
----------------------------------------------------------------------
El articulo no especifica con suficiente detalle el vector exacto de features que Edge Impulse entrego a la DNN y presenta una inconsistencia al describir una entrada de 3 neuronas mientras tambien afirma utilizar features espectrales. Por ello, este preprocesamiento constituye una replica reproducible inspirada directamente en las caracteristicas mencionadas en el articulo, no una reconstruccion exacta del pipeline interno de Edge Impulse.

Entonces nosotros implementamos una réplica metodológica basada en los parámetros explícitamente reportados por Arciniegas et al., conservando la frecuencia de muestreo, segmentación FFT, solapamiento, arquitectura de capas ocultas e hiperparámetros de entrenamiento. Debido a que el artículo no detalla completamente el vector de características generado por Edge Impulse, la etapa de extracción de características fue reconstruida en Python a partir de las características temporales y espectrales descritas por los autores.
